# Mission T

브라우저에서 하는 3D 스턴트 게임이에요. 흡착 바퀴로 높이 21m의 오버행 램프를 타고 올라가 공중으로 날아오른 뒤, 추진기로 자세를 잡고 바퀴부터 착지하면 돼요.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:5173`을 열면 돼요. 설치할 패키지는 없고(Node.js만 필요), Three.js는 CDN에서 불러와요.

## 조작

| 키 | 동작 |
|---|---|
| ↑ / W | 전진. 누르고 있는 동안 램프에 흡착돼요 |
| ↓ / S | 후진 |
| ← → / A D | 공중 회전 |
| Space | 리프트 분사. 위로 띄우거나 착지 전에 감속해요 |
| E | 부스트 분사. 앞으로 밀어요 |
| R / Enter | 다시 시작 |
| P / Esc | 일시정지 |
| C | 카메라 전환 (측면, 추적, 드론, 지면) |
| M | 모드 전환 (램프, 점프, 하이웨이, 레이스) |

터치 기기에서는 화면 버튼이 나타나요.

## 모드

램프와 점프는 같은 코스를 쓰고, 출발 위치와 목표 구역만 달라요.

- **램프**: 램프 바로 앞에서 출발해요. 끝까지 오르면 오버행 립에서 뒤집힌 채로 날아가요. 반 바퀴 돌려 바로 세우고, 리프트로 감속해서 목표 구역(램프 앞 24m)에 착지하세요. 램프 꼭대기 지붕 위에 착지하는 것도 가능해요.
- **점프**: 178m 뒤에서 출발해요. 달리다가 리프트로 떠올라 주차된 차량 5대를 넘고, 76m 지점 목표 구역에 착지하세요.
- **하이웨이**: 끝없이 이어지는 왕복 6차선 고속도로를 자유롭게 달려요. 도로는 직선, 완만한 스위퍼, 반경 230~380m의 급코너, S자 구간이 이어지고, 2.4km 이상 간격으로 인터체인지(고가 교차로와 양쪽 진출입 램프)가 나와요. 급코너 바깥쪽에는 빨간 갈매기 표지판이 서 있어요. 램프는 풍경이라 들어갈 수는 없어요. 도로는 출발점에서 앞뒤 양쪽으로 끝없이 이어지고, 차는 360도 회전과 유턴이 가능해서 어느 방향으로든 달릴 수 있어요(역주행 포함). 추적 카메라는 항상 내 차가 향한 방향 뒤에 붙어요. 매번 새 도로가 만들어지고, 최고 기록은 한 번에 달린 거리(km)예요.

### 하이웨이 조작

| 키 | 동작 |
|---|---|
| ↑ / ↓ | 가속 / 제동·후진 |
| ← → | 조향 |
| Shift | E-브레이크. 뒷바퀴가 잠겨 꼬리가 미끄러져요. 조향과 함께 쓰면 드리프트 (스키드 마크, 타이어 연기, 스키드 소리) |
| E | 부스트 (최고 약 330km/h, 게이지 소모) |
| Space | 짧게 누르면 홉, 누르고 있으면 공중 호버. 차량 위를 넘어갈 수 있어요 |
| C | 카메라 (추적, 후드, 드론, 측면) |
| R | 새 도로로 다시 시작 |

부스트 게이지는 쓰지 않을 때 천천히 다시 차요. 가드레일에 부딪히면 튕겨 나오고 속도가 줄어요.

중앙 분리대는 점프로 넘을 수 있어요(높이 약 0.85m 이상). 넘어가면 반대편 차선을 역주행하게 돼요. 가볍게 스치는 접촉은 튕겨 나오지만, 다른 차와 시속 50km 이상으로 정면·추돌·측면 충돌하면 차가 박살나고 게임 오버예요. 결과 카드에는 달린 거리, 최고 속도, 추월 수, 주행 시간, 충돌 속도가 나와요.

## 레이스 (온라인 멀티플레이)

상단 메뉴의 **Race**를 누르면 방이 만들어지고 주소가 `?room=코드`로 바뀌어요. 이 주소를 공유하면 최대 5명이 같은 방에 들어와요. 6번째 사람은 "방이 가득 찼어요" 안내를 받아요.

- **시작**: 방 안의 누구든 `Enter`(또는 Retry)를 누르면 모두 같은 새 도로에서 3·2·1 카운트다운 후 출발해요.
- **목표**: 5km 앞의 FINISH 게이트를 먼저 통과하면 이겨요.
- **규칙**
  - 교통 차는 없어요.
  - 플레이어끼리는 실제로 부딪혀요. 가볍게 닿으면 튕기고, 시속 50km 이상 상대 속도로 들이받으면 차가 박살나고 리타이어예요.
  - 레이스 중에는 일시정지할 수 없어요.
- **결과**: 오른쪽 위 방 패널에 실시간 순위와 진행 거리가 나와요. 결승이나 리타이어 후에는 결과 카드에 전체 순위가 나와요. 첫 완주자가 나오고 60초가 지나면 레이스가 끝나요.
- **최고 기록**: 완주 시간이 Best에 저장돼요.

각 브라우저가 자기 차를 계산하고, 도로 위치를 초당 20번 서버로 보내요. 다른 플레이어 차는 0.1초 늦게 부드럽게 보간해서 그려요. 서버는 방, 출발 신호, 순위만 관리해요. 방 로직은 [server/room-core.js](server/room-core.js) 하나이고, 로컬 Node 서버와 Cloudflare 배포가 같은 코드를 써요.

### 배포 (Cloudflare Workers)

지금 배포 주소는 **https://mission-t.mission-t.workers.dev** 예요. 도메인 없이 무료 주소로 열리고, PC를 꺼도 돼요.

- 게임 파일은 Workers 정적 에셋으로 올라가요. 레이스 방은 방 코드마다 하나씩 Durable Object가 맡아요([worker/index.js](worker/index.js), [wrangler.toml](wrangler.toml)).
- 다시 배포하려면 `npm run deploy`를 실행해요. 처음 한 번은 Cloudflare 로그인 창이 떠요.
- 로컬에서 Workers와 똑같이 돌려 보려면 `npm run worker:dev`를 실행해요.
- 업로드할 파일은 [.assetsignore](.assetsignore)에 허용 목록으로 적혀 있어요. 폴더에 새 파일이 생겨도 이 목록에 넣기 전에는 공개되지 않아요.

무료 사용량 관리
- 무료 플랜은 한도를 넘어도 요금이 나가지 않아요. 그 기능만 멈추고 매일 00:00 UTC(한국 시간 오전 9시)에 초기화돼요. 정적 게임 파일은 한도와 상관없어요.
- 위치 전송: 카운트다운·레이스 중에는 초당 20번(부드러운 상대 차), 로비에서는 초당 2번, 탭이 숨겨지면 보내지 않아요.
- 2분 동안 키·클릭·터치 입력이 없으면 방에서 나가요. `Enter`를 누르면 같은 방에 다시 들어가요.
- 서버가 오늘 사용량을 추정해 세요(`worker/index.js`의 `Usage`). 95%가 되면 새 접속과 새 레이스를 막고 "오전 9시 이후 다시"라고 안내해요. 이미 달리던 레이스는 끝까지 진행돼요.
- 사용량은 주인 브라우저에서만 보여요. `?owner=<키>`로 한 번 접속하면 키가 그 브라우저에 저장되고, 왼쪽 위 Best 아래에 "Free allowance 23% today"처럼 표시돼요(80% 이상이면 빨간색). 키는 Worker 비밀값 `OWNER_KEY`이고, 바꾸려면 `npx wrangler secret put OWNER_KEY`를 실행해요.
- 이 사용량은 추정치예요. 정확한 값은 대시보드의 **Workers & Pages → mission-t → Metrics**에서 확인하세요.
- 공개 주소이니 Crosner 폰트("Free Version")의 사용 조건을 확인하세요.

### 로컬에서 실행하기

`npm start` 후 `http://localhost:5173`에 접속하면 레이스까지 로컬에서 동작해요. 같은 PC의 여러 탭이나 같은 와이파이의 다른 기기로 테스트할 수 있어요. 잠깐 바깥 사람과 해 보려면 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)를 설치하고 다른 터미널에서 `npm run tunnel`을 실행하세요. 계정 없이 쓸 수 있지만, 실행할 때마다 바뀌는 `https://….trycloudflare.com` 임시 주소가 나와요.

## 설정

설정 패널에서 중력, 속도, 추력, 회전, 자세 유지, 연료, 착지 허용치, 시뮬레이션 속도를 바꿀 수 있어요. 프리셋은 기본, 아케이드, 하드, 저중력 네 가지예요.

## 내 차량 모델 넣기

상단 **Garage**에서 기존 Vertigo GT와 추가 차량 5종(마칸 4S, 911 카레라, 718 카이맨, 타이칸, 911 GT3 RS)을 선택할 수 있어요. `http://localhost:5173/garage.html`에서 3D 회전·앞뒤측면·휠 회전을 확인하고 **이 차량으로 주행**을 누르세요. 직접 열려면 `?car=718-cayman`처럼 차량 ID를 주소에 붙이면 돼요. 모든 차는 동일한 아케이드 물리를 사용하며, 선택한 외형은 로컬 플레이어에게 적용돼요. Blender 원본과 제작 정보는 `assets/vehicles/README.md`, 재생성 스크립트는 `tools/build_porsche_fleet.py`에 있어요.

지금 `assets/car.glb`에는 Blender로 만든 오리지널 차량 **Vertigo GT**가 들어 있어요. 원본 작업 파일은 `assets/vertigo-gt.blend`예요. 바퀴는 `wheel_FL/FR/RL/RR` 오브젝트로 나뉘어 있어서 게임에서 굴러가요.

`assets/car.glb`(또는 `.gltf`)를 다른 모델로 바꾸면 그 모델이 쓰여요. Draco 압축도 지원해요. 모델이 없으면 기본 로버를 쓰고, 이때 콘솔에 404가 한 줄 찍히는 건 정상이에요.

맞춤 설정은 [src/car-model.js](src/car-model.js)의 `CAR_MODEL`에서 해요.

| 항목 | 설명 |
|---|---|
| `length` | 모델의 가장 긴 수평 길이를 이 값(m)에 맞춰 크기를 조정해요. 물리상 차체는 길이 약 4.5m, 축간거리 2.76m예요 |
| `rotationY` | 차 앞이 +x를 보도록 회전해요. 앞뒤가 반대거나 옆을 보면 `Math.PI`, `±Math.PI / 2`를 넣어 보세요 |
| `groundOffset` | 모델 바닥 위치예요. 기본 -0.6이면 타이어가 노면에 닿아요 |
| `wheelPattern` | 이름이 이 패턴에 맞는 노드가 바퀴로 회전해요 (기본: wheel, tire, tyre, rim) |
| `wheelAxis`, `wheelRadius` | 바퀴 회전축과 반지름 |

분사 화염과 리프트 조명은 모델과 상관없이 차체 기준 위치에 붙어요. 위치를 바꾸려면 [src/rover.js](src/rover.js)의 노즐 좌표를 수정하세요.

## 저작권

레퍼런스 게임의 **동작 원리와 조작감 수치**만 참고해서 새로 만들었어요(분석 내용은 [ANALYSIS.md](ANALYSIS.md)). 레퍼런스의 코드, 3D 차량 모델, 폰트, 로고, 상표, 이름, 시각 디자인은 쓰지 않았어요. 차량·램프·텍스처·사운드는 모두 코드로 직접 만들었고, 외부 라이브러리는 Three.js(MIT 라이선스)뿐이에요.
